Phase 03 · Knowledge

Đào Tạo
& Tri Thức Nền Tảng

Xây dựng "bộ não" cho GPT — tri thức chuyên môn, ngữ cảnh dự án, và dữ liệu cá nhân hóa để GPT hiểu sâu về lĩnh vực của bạn.

📚 Cách đào tạo dữ liệu cho Custom GPT
1
Paste vào Instructions
System prompt được generate ở bước 6 → paste vào ô "Instructions" trong GPT Builder
2
Upload Knowledge Files
Upload PDF, TXT, DOCX chứa tài liệu chuyên môn vào mục "Knowledge" để GPT tham chiếu
3
Memory qua Conversation
Dùng lệnh /learn trong chat để GPT ghi nhớ thông tin quan trọng dài hạn
💡 Đây sẽ được nhúng trực tiếp vào system prompt. Nội dung ngắn gọn, có cấu trúc — GPT sẽ hiểu tốt hơn.

Phase 04 · Memory

Bộ Nhớ
Dài Hạn

ChatGPT không có native long-term memory theo mặc định — nhưng bạn có thể mô phỏng bộ nhớ dài hạn qua các kỹ thuật dưới đây.

⚠️ ChatGPT Plus có tính năng Memory, nhưng Custom GPT cần cấu hình riêng. Prompt dưới đây dạy GPT cách xử lý memory qua conversation.
Full Memory Engine
GPT tự động đánh dấu thông tin quan trọng bằng ⟨MEM⟩, tạo Memory Snapshot khi kết thúc phiên, và đọc lại snapshot ở đầu phiên mới. Mạnh nhất, yêu cầu bạn paste snapshot.
Khuyên dùng · Dài hạn nhất
ChatGPT Memory Plugin
Tận dụng tính năng Memory có sẵn của ChatGPT Plus. GPT chủ động yêu cầu save_memory khi gặp thông tin quan trọng.
ChatGPT Plus Only
Manual Context
Người dùng tự dán ngữ cảnh vào đầu mỗi phiên. Đơn giản, không cần cài đặt, phù hợp với workflow tự quản lý.

Lệnh Hệ Thống (Slash Commands)
/status Báo cáo trạng thái memory và ngữ cảnh hiện tại
/recap Tóm tắt những gì đã thảo luận trong phiên này
/learn [nội dung] Ghi nhớ thủ công một thông tin cụ thể vào long-term memory
/profile Hiển thị toàn bộ hồ sơ người dùng đã ghi nhớ
/reset Xóa toàn bộ ngữ cảnh (yêu cầu xác nhận)

Phase 06 · Output

Đã Hoàn Thành ✨

Custom GPT của bạn đã sẵn sàng. Copy prompt và làm theo hướng dẫn để kích hoạt trên ChatGPT.

🚀 Cách cài đặt Custom GPT trên ChatGPT
1
Mở GPT Builder
Vào chatgpt.com → Explore GPTs → Create → Configure tab
2
Paste System Prompt
Copy "System Prompt" bên dưới → paste vào ô "Instructions" trong GPT Builder
3
First-Run Onboarding
Khi đã tạo xong GPT, paste "First-Run" vào chat đầu tiên để GPT nhận hồ sơ của bạn
