Mô hình · Memory Pipeline
🔋 Full Engine — Memory hoàn chỉnh⟨MEM⟩ tự động, snapshot cấu trúc, lệnh /status /recap /learn. Tốt cho dự án dài hạn.

🔧 Manual — Tự quản lýGem không theo dõi bộ nhớ. Bạn cung cấp ngữ cảnh khi cần. Tốt cho phiên độc lập.

/reset — Xóa ngữ cảnhReset phiên (luôn hỏi xác nhận trước)
